# CFIT Timetable — Product Showcase

A lightweight, mobile-first project showcase for the 2026 Wintec industry internship project.

**Public website:** https://cfit-timetable-development.github.io/CFIT-Showcase/

The site currently displays a placeholder while the full showcase is developed. The printed QR code should point to this stable GitHub Pages URL, **not** to the GitHub repository. Verify the live site and scan the QR code with a phone before sending the poster to print.

## Publishing

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/(root)`. The current site uses `index.html` directly, without a build step.

Future versions may replace it with React and Vite, using `base: '/CFIT-Showcase/'`. Keep the public URL unchanged so existing printed QR codes continue to work.

Product source: https://github.com/CFIT-Timetable-Development/CFIT-Timetable-System

Large master video files belong outside this repository. A future showcase may link to or embed a video hosted elsewhere.
